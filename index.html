01About

01 / MAIN PROJECT 개인 학습 프로젝트

Circuit Lab

직접 회로를 그리고, 전압과 전류를 관찰하는 브라우저 실험실.

문제
회로 수식과 파형을 별개로 공부할 때 생기는 이해의 간격.
역할
학습 요구와 조작 개선 방향 제시, 결과 확인. AI 보조로 설계·구현·검토 진행.
로그인 후 Circuit Lab 실행 ↗

Apple 계정으로 로그인한 소유자 전용입니다. Naver 계정 공유는 아직 제공하지 않습니다.

구현된 해석 기능

  • DC 해석
  • 시간응답
  • AC 해석
  • 종속원
  • 이상 OP AMP
  • DC 테브난·노턴
  • 계산 취소
구현 범위와 한계 보기

CIRCUIT-024 기준 마지막 시간 구간 적분과 지수·SI 접두어 변환을 보완했습니다. 기능별 수용 범위와 시험 기록을 구분해 관리했습니다.

전체 시험 통과나 실제 회로의 모든 동작을 보장하지 않습니다. 실제형 OP AMP, AC 포트 확장, 일부 모바일 조작은 완료 기능으로 소개하지 않습니다.
